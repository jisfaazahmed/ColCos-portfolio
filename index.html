01 — Platform Overview

Built to modernize
Sri Lankan beauty commerce

Transforming fragmented social media commerce and manual spreadsheets into a seamless, high-converting digital storefront and unified merchant operations center.

The Challenge: Colombo Cosmetics was experiencing rapid growth across Sri Lanka through social channels and messaging apps. However, managing inventory counts, calculating profit margins, processing card and Cash on Delivery payments, and manually answering order inquiries on WhatsApp was straining daily operations.

The Solution: We architected and delivered a full-stack e-commerce web platform (colombocosmetics.lk ↗) optimized for mobile shopping. Customers enjoy high-speed browsing of skincare, luxury perfumes, attars, and beauty bundles with instant search and transparent delivery tracking.

The Engine Behind the Store: An authenticated merchant command center empowers administrators with real-time sales analytics, multi-variant inventory control, automated coupon generation, hero banner scheduling, and customer support audit trails — secured with multi-factor authenticator verification.

Consumer Storefront
Frictionless browsing across skincare, attars, and cosmetics with real-time stock availability, verified reviews, variant pickers, and persistent drawer cart.
Localized Checkout Pipeline
Tailored for Sri Lankan buyers with flat-rate island-wide delivery (Rs. 400), coupon code discounts, and dual payment support: Cash on Delivery or instant card processing via Payments.lk.
Admin Command Center
Comprehensive inventory management, revenue and profit analytics, order dispatch pipeline, bundle creators, and 2FA authenticator security gate.

05 — Engineering Journey

From discovery to
production deployment

How the system was designed, validated, and rolled out to replace legacy spreadsheets with an end-to-end commerce architecture.

01

Requirements Discovery & Commerce Modeling

Analyzed customer purchase habits in Sri Lanka, inventory replenishment bottlenecks, and delivery workflows to establish the schema for variants, wholesale costs, and order statuses.

02

Design System & Mobile-First UX

Formulated the brand aesthetic: editorial serif headlines (Playfair Display), clear sans-serif body typography (Poppins), and signature hot-pink glows with high-contrast readable dark cards.

03

Full-Stack SSR Implementation

Engineered the solution on TanStack Start and React 19. Implemented type-safe server functions, cache invalidation with TanStack Query, and lightning-fast page transitions.

04

Payment Gateways & Webhooks

Built dual checkout flows for COD and Payments.lk card processing. Implemented signed webhook verification endpoints to handle payment states securely and trigger order confirmations.

05

Admin Center & 2FA Security Gate

Constructed the administrative suite with 2FA authenticator verification, inventory stock controls, wholesale margin tracking, bundle management, and automated database audit logging.

Architecture & Execution

Executed as an end-to-end engineering initiative covering system architecture, user interface design, full-stack implementation, and deployment:

  • Full-stack architecture leveraging TanStack Start (SSR) & React 19
  • Tailwind CSS v4 design system with custom OKLCH color palettes
  • Supabase PostgreSQL relational modeling, migrations, and Row-Level Security
  • Payments.lk Node SDK card integration with HMAC webhook validation
  • Cash on Delivery order verification & automated invoice generation
  • Multi-factor authenticator gate securing the administrative workspace
  • Real-time stock reservation and atomic inventory deduction logic
  • Transactional email automation via Nodemailer and WhatsApp order integration
